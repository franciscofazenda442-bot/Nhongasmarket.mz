# NhonguistaMarket V1.1 🇲🇿
Marketplace frontend para produtos novos e usados.

## Novidades
- Stock por produto e controle ao adicionar ao carrinho.
- Chat local comprador/vendedor por produto.
- Botão WhatsApp com mensagem automática.
- 10+ novos campos no anúncio:
  Marca, Modelo, Cor, Tamanho/Dimensão, Material, Peso, Validade, Localização, Contacto, WhatsApp e Entrega.
- Detalhes completos do produto.

## Abrir
Extraia o ZIP e abra `index.html` no navegador ou no VS Code.

## Nota
O chat desta versão é demonstrativo/local no navegador. WhatsApp abre a conversa através do número informado pelo vendedor.
Para chat real entre contas, pagamentos, pedidos e stock sincronizado entre dispositivos, a próxima versão deve usar backend + banco de dados.
